# Contributing to Timers

Thanks for helping improve Timers. Bug reports, feature requests, and other issues are welcome in
the public issue tracker.

Pull requests are welcome as patch submissions. This repository is a maintained public mirror, so
contributor branches are not merged directly into public `main`. Instead, an accepted patch is
applied to the private development source, reviewed and tested there, then mirrored back here.
Contributor attribution is preserved in the resulting public change, and the original pull request
remains part of that record.

This workflow can take a little longer than a direct merge, but accepted work does return to the
public repository. Please keep pull requests focused and describe the behavior being changed and
how you tested it.

For security-sensitive reports, use GitHub's private vulnerability reporting instead of opening a
public issue.
